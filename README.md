# Sharkari Guru

A modern, mobile-first portal for Sarkari jobs, results, admit cards, and exam notices. Built as a UI with dummy data — not affiliated with any government body.

## Run locally

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

```bash
npm run lint
npm run build
```

## What’s included

- Homepage with search, categories, latest jobs/results, and closing-soon cards
- Listings with state, qualification, and exam-body filters
- One-page notice details (dates, eligibility, official link)
- Hindi/English, dark mode, saved posts (localStorage), exam calendar
- About, contact, and disclaimer pages

Apply and result links always go to official sites. Sharkari Guru does not accept applications.
